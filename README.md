# StitchSure

A prototype for tailoring change requests. A customer asks for a change to a garment, the tailor reviews it, the customer approves, and the worker carries it out. Login, messages and data are simulated and nothing is saved.

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
